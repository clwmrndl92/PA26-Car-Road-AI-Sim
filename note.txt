Phase 0 — 기반 안정화 (먼저, 작업량 작음)

종방향 제어 수정 — 피드포워드 추가

게이트: 차가 목표 속도를 매끄럽게 추종하고, 앞차 급정거에 안 박으면 통과.

검증 대상	필요한 시나리오
곡선 구간 — 코너 진입하며 감속
앞차 급제동 — 정속 추종 중 갑자기
넓은 속도 범위 — 0에서 최고속까지, 정지·재출발
완전 정지 — 멈춘 뒤 안 밀리는지
목표 속도 계단 변화 — 제한속도 바뀌는 구간

월드 좌표를 ground truth로 — 차량 상태는 (x, y, heading, v), (s, d, ḋ, d̈)는 매 프레임 투영으로 얻는 파생값
LaneBand 구조 — centerOffset / width / direction / type / boundaryMark / speedLimit, GetLateralProfile(s) 쿼리
참조선을 도로 중앙으로 이동, d 범위를 도로 전체로 확장. 이 단계에선 direction을 전부 같은 방향으로 채워도 됨
레인 그래프는 유지 — 라우팅(위상)용으로 계속 씀. GetLeft()/GetRight()만 지역 계획에서 제거

게이트: 기존과 동일하게 주행하는지.

Phase 2 — 후보를 횡오프셋으로 전환
후보 생성 — d 샘플(7개 정도) × 목표속도(3개). 차선 개념 제거
5차 다항식 궤적 — (d, ḋ, d̈) → (d_target, 0, 0), S커브 자동 생성
해석적 곡률 → w3 + 마찰원 초과 후보 사전 탈락
안전 검사 재작성 — 레인 단위 gap이 아니라 궤적점 vs 주변차 예측경로 거리로 통일
d_target 상태 + w4(관성)
w5 — d_reference 끌림 = 차선 유지. 별도 모드 아님
SetCurrentLane 즉시 교체 제거 — 순간이동 버그가 구조적으로 소멸. 차선 인덱스는 round(d/laneWidth)로 필요할 때만 조회

게이트: 차선 변경이 1~2초에 걸쳐 부드럽게, 중간에 안 뒤집히는지.

Phase 3 — 새 행동
정지 후보 추가 — 신호등/정지선.
막힘 감지 → 우회 시도 — 앞차 정지 상태 판정 + 옆으로 비켜가기
w6/w7 — 대형차 회피, 가장자리 여유 — 구현 거의 공짜인데 사람 같아 보이는 효과가 큼
역주행 차로 진입 — 마지막. 안전 검사를 (v_나 + v_대향) × 왕복시간으로 재계산, 커밋 상태(point of no return) 별도 관리
